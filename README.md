# MurderMysteryUtils - Minecraft Forge Mod (1.12.2)

## Описание

Мод **MurderMysteryUtils** добавляет набор полезных функций для игры в **Murder Mystery** на Minecraft 1.12.2 (Forge). Текущая версия: **3.1**.

Приоритетные серверы: YukiKawaii, Keksik9000: DexLand, MasedWorld, MineBlaze, CheatMine, MineBerry, MinePeak. На других серверах часть модулей может не работать: там могут быть другие роли, предметы убийцы и форматы чата.

---

## Модули

### Игра и роли
- **AutoNext** - автоматический переход в следующую игру (`/next`) при определённых ролях, также можно включить переход в конце игры. Сообщения настраиваются.
- **AutoRoleAnnounce** - отправка вашей роли в party chat (`/pc`).
- **MurderAlert** - оповещение об убийце.
- **AntiLag** - уменьшение лагов на картах AncientTomb и Subway.

### Визуал
- **ESP** - отображение игроков, есть индикатор друзей (Friend Indicator).
- **BowESP** - отображение лука.
- **ItemESP** - отображение предметов.
- **FlowerPotESP** - отображение цветочных горшков.
- **Tracers** - линии к игрокам, учитывают роли Murder Mystery.
- **NameTags** - отображение скина, ника и пинга игроков (настраивается).
- **ShowNames** - восстановление скрытых никнеймов.
- **BarrierVision** - видимость барьеров.
- **FullBright** - полная яркость.
- **AntiBlind** - убирает эффект ослепления.
- **CustomTime** - настройка времени в мире, есть режим RealTime (по реальному времени).
- **CustomWeather** - настройка погоды, включая снег (`Weather:snow`).
- **FreeCam** - свободная камера.
- **CameraClip** - камера от третьего лица проходит сквозь блоки и не упирается в них.
- **NoPitchLimit** - снятие ограничения угла наклона камеры.

### Движение
- **Fly** - режим полёта.
- **Sprint** - автоматический спринт.
- **InvMove** - движение при открытом инвентаре.
- **AntiAFK** - защита от AFK.
- **FakeGM** - фейковый режим игры: Survival, Creative, Adventure, Spectator. Полёт включается, если сервер разрешает. При выключении возвращается ваш режим.
- **FakePing** - подмена пинга.
- **BowAim** - помощь в прицеливании луком.

### Чат
- **ChatTranslator** - перевод чата и party chat на основе Google Translate, есть отправка переведённых сообщений в чат (в переводе возможны ошибки).
- **ChatIgnore** - игнор игроков, в том числе находящихся в игре.
- **ChatColor** - цветной (радужный) чат.
- **ChatLogger** - логирование чата.
- **TabCompleteFix** - исправление таб-комплита на аренах.
- **NameProtect** - визуальное скрытие ника и скина.

### Интерфейс и прочее
- **HUD** - информация об убийце и детективе, расположение можно менять.
- **ArrayList** - список включённых модулей.
- **CustomTab** - настройка списка игроков (таба).
- **DiscordRPC** - статус в Discord.
- **Scripts** - система Lua-скриптов.
- **Темы GUI меню** - выбор темы оформления.

> Модуль **Spammer** удалён в версии 3.1.

## Команды

Команды работают как с префиксом `.`, так и через `/mmutils`.

| Команда | Описание |
|---|---|
| `.bind` | Бинды модулей и команд чата. Можно назначить несколько действий на одну кнопку. Пример: `.bind add f /next` |
| `.t` / `.toggle` | Переключить модуль. Пример: `.t FullBright`. Работает и в биндах |
| `.getskin [ник]` | Выгрузка скина игрока (Mojang, TLauncher, Ely.by) |
| `.friend` | Список друзей |
| `.ignore` | Список игнора |
| `.sendlang язык текст` | Отправить текст на другом языке |
| `.gm` | Смена режима игры (фейк) |

## Установка

1. Установите **Minecraft 1.12.2** с **Forge**.
2. Скачайте последнюю версию мода на странице [Releases](https://github.com/inkognito338/MurderMysteryUtils/releases/latest).
3. Поместите `.jar` в папку `mods`.
4. Запустите Minecraft через профиль **Forge**.

## Важная информация

- **Серверы.** Автор не несёт ответственности за блокировки и сброс статистики на серверах, мод может нарушать правила серверов.
- **Онлайн-функции.** В моде есть OnlineMode (чат между пользователями мода), чёрный список, UpdateChecker (с зеркалами: GitHub, Codeberg, GitLab, GitFlic, Statically, jsDelivr) и отображение разработчиков/спонсоров. Lua-скрипты загружаются с GitHub и работают как безопасные обработчики проверок: в их окружении отключены `load`, `loadstring`, `dofile`, `loadfile` и `require`, доступа к файловой системе и ОС у них нет.
- **Аналитика.** Мод отправляет анонимную статистику (Google Analytics и Mixpanel): версии Minecraft, Forge, Java, ОС, объём RAM, наличие OptiFine, количество модов, язык, масштаб интерфейса, дальность прорисовки и случайный ID клиента (`murdermysteryutils_client_id.txt`). Ник, данные аккаунта, чат и адреса серверов **не собираются**. Подробности в файле лицензии.
- **Сервер UltraMc.** Мод добавляет сервер автора (UltraMc) в список серверов при первом запуске и примерно раз в 90 дней. Вы можете удалить его из списка в любой момент.
- Если вы не согласны с этими пунктами, используйте версию **2.0 или ниже** в соответствии с лицензией.
